# APS Engenharia Civil — Plataforma Web de Gestão e Apresentação Profissional

Plataforma web integrada voltada à gestão operacional de pequenas e médias reformas civis e acompanhamento transparente de clientes, desenvolvida como projeto acadêmico de extensão universitária no Centro Universitário Senac-RS (UniSenac).

## 👷‍♂️ Parceiro Extensionista
* **Profissional:** Alexandre Pereira Santos (Engenheiro Civil)
* **Registro de Classe:** CREA-RS 133612
* **Atuação:** Obras civis, reformas, medições e laudos técnicos

## 🚀 Funcionalidades do MVP
1. **Camada Pública Institucional:** Apresentação curricular, especialidades e canal direto para contato via WhatsApp.
2. **Painel do Engenheiro:**
   * Diário de Visita Técnica e vistorias de campo.
   * Calculadora técnica de quantitativos com aplicação automática da margem de segurança de 10% para quebra de insumos (pisos, rejuntes e argamassa).
3. **Portal do Contratante:** Linha do tempo atualizada da obra com relatórios e controle de prestação de contas.

## 🛠️ Tecnologias Utilizadas
* **HTML5 Semântico:** Estruturação acessível e otimizada dos elementos da interface.
* **Bootstrap 5 (via CDN):** Framework de estilos para interface responsiva, sistema de grid e componentes de formulário.
* **Bootstrap Icons:** Biblioteca de ícones vetoriais leves para sinalização visual de ações (WhatsApp, calculadora, relatórios).
* **CSS3 Personalizado:** Estilização com paleta corporativa oficial da marca (Azul Marinho #122A44 e Dourado #B38E46).
* **JavaScript Vanilla (ES6+):** Programação das regras de negócio, cálculo de quantitativos (+10% de perda) e manipulação dinâmica do DOM sem dependências externas.
